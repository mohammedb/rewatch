Focus for next game:

Hands off the game.

Rewatch only watches from the outside, the same way OBS's display capture does. It never goes near League itself, and the code is open, so you can check.

Never

  • Reads or changes the game's memory.
  • Injects or hooks anything into the game.
  • Draws over the game. No overlay, no in-game window.
  • Touches your input. No keyboard or mouse hooks, no automation.

Instead

  • Picture from Windows' own screen capture.
  • Sound from Windows' own per-app capture.
  • Events from Riot's Live Client Data API, which Riot documents for tools like this.
  • Your frame rate left alone: encoding runs on the graphics card, and files are joined after the game.
Read the code on GitHub

Nobody outside Riot can promise what Vanguard will accept in the future. These are the same outside-only methods mainstream recorders use, which is the safest ground there is.
